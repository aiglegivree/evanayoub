# DISAL — Visual Material Recognition photos

Place project pictures in this folder (for example, `img1.jpg` and `img2.jpg`).

In the root `script.js`, find the Deep Learning for Visual Material Recognition
project and add image paths to its `gallery` in display order. The current cover
is `img1.jpg`:

```js
gallery: [
  "assets/projects/material-recognition/img1.jpg",
  "assets/projects/material-recognition/img2.jpg",
],
```

Use the exact filenames and extensions, including capitalization. JPG, PNG, and
WebP images are supported. The first image becomes the card's cover; the carousel
and larger viewer are enabled automatically. Until then, the card displays
"Photos coming soon".
